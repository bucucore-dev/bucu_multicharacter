# bucu_multicharacter

> Cinematic Multi-Character Selection & Onboarding Interface for FiveM.

---

## 🌟 Overview

`bucu_multicharacter` delivers a modern character selection screen with smooth camera transitions, registration forms, spawn location selector, and starter pack injection.

## 📦 Features
- **4 Character Slots**: Expandable multi-character slots with status cards.
- **Cinematic Sky Camera**: Smooth aerial camera glide upon connection.
- **Citizen Registration**: Full name, Date of Birth, gender, and nationality inputs with real-time validation.
- **Spawn Point Selector**: Los Santos International Airport, Pillbox Hill Hospital, or Train Station.
- **Starter Pack Injection**: Automatically provisions cash, bank balance, and starter inventory items upon first arrival.
